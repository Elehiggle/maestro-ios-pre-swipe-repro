# Public evidence copies

Public logs and receipts retain all content lines. Private local paths and simulator/install UUIDs use placeholders. Event values, timestamps, geometry, query counts and artifact hashes are unchanged. `MANIFEST.json` hashes the public copies; `redaction-receipt.json` records original/public hashes and byte counts.

`<REPRO_ROOT>` means the clone/extraction directory; `<MAESTRO_2_11_0_ROOT>` means the isolated official CLI. Java-cache placeholders refer to temporary `-Duser.home` directories. The included run receipts record the measured invocation; the README gives portable clone/build/run commands.
